# ST:talk 행사 개요

ST:talk는 서울과학기술대학교 동문 선배님과 재학생이 진로 경험을 나누는 소규모 테이블 토크입니다. 취업뿐 아니라 창업과 대학원 진학 경험도 대화 범위에 포함합니다. 강연회가 아니라, 선배님 한 분과 학생들이 한 테이블에 앉아 이야기하는 자리입니다.

이 사이트는 초청받은 동문 선배님께 행사 취지, 진행 방식, 일정을 설명하기 위한 것입니다. 재학생 모집 페이지가 아니며, 사이트 안에 참가 신청 양식은 없습니다. 참여 여부는 10월 15일(목)까지 카카오톡 오픈채팅으로 답변을 부탁드립니다.

## 아직 정해지지 않은 것

- 세부 시간표는 가안이며 바뀔 수 있습니다.
- 차시 사이에 학생들이 어떻게 자리를 옮기는지는 정해지지 않았습니다.
- 자기소개 양식과 예상 질문 목록은 위원회가 선배님께 따로 보내드립니다. 자세한 내용은 그때 안내합니다.
- 강연비의 금액은 사이트에 적지 않습니다. 교통 지원은 확정된 정보가 없습니다. 궁금한 점은 카카오톡 오픈채팅으로 확인해 주세요.
